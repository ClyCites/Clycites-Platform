# Pilot support and evaluation

Pilot support cases track user assistance and workflow defects. Operational incidents track security,
privacy, availability, integrity, or provider impact. Escalation links the two records; histories remain
separate.

Evaluation reports baseline coverage, metric quality, feedback categories, support state, and open
incidents. Reports must label synthetic, partial, questioned, rejected, and unmeasured evidence. A human
records a recommendation and a different human approves it against the same evidence snapshot hash.
`GO`, `CONDITIONAL_GO`, and `NO_GO` are not produced automatically.
